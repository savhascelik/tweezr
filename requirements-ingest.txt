# The transcription stack. Needed to build a corpus, and to accept uploads.
#
#   pip install -r requirements.txt -r requirements-ingest.txt
#
# Kept in its own file rather than merged, for two reasons that still hold now that the
# deployed image installs both. It is about 260 MB with the model, which is worth being an
# explicit choice rather than a surprise. And the server degrades honestly without it:
# /api/upload/status reports uploads as off and the interface says so, so a minimal
# deployment is a real option and not a broken one.
#
# What it is NOT about any more: keeping it out of the container. Uploads were the reason
# that argument stopped making sense — a library a visitor cannot add to is a demo of
# itself.

-r requirements.txt

# Word-level timecodes. Runs on CPU; no GPU needed. The multilingual models come from the
# same package, which is why the product is not English-only.
faster-whisper==1.1.1

# faster-whisper 1.1.1 imports `requests` but did not pull it in transitively in this
# environment. Pinned explicitly, otherwise the first run is a ModuleNotFoundError.
requests==2.34.2

# --- faster-whisper's own dependencies, pinned on purpose ---
#
# These are transitive, so pip would resolve them itself. Two reasons not to let it.
#
# They carry almost all of the image. An unpinned rebuild moved the install layer from
# 592 MB to 626 MB with nothing in this file changed, which means the size quoted in
# DEPLOY.md is only true for as long as nobody rebuilds.
#
# And they are the inference stack. faster-whisper calls ctranslate2 directly and reads
# the model through huggingface-hub; a release of either landing between a passing test
# run and a deploy is the sort of failure that arrives at the worst moment and looks like
# our bug. The version below is the one every measurement in this repository was taken
# against, inside the container, on linux.
#
# Not a full lock: the remaining transitive packages are small pure-Python ones
# (idna, packaging, filelock and similar) that cannot plausibly break this and do not
# move the size. Pinning those too would mean regenerating a lock file on every bump for
# no protection gained.
ctranslate2==4.8.2
onnxruntime==1.29.0
av==18.1.0
tokenizers==0.23.2
huggingface-hub==1.30.0
numpy==2.4.6
